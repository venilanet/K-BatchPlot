K-批量打印 · 使用说明
============================================================
（AutoCAD / 天正 图框型批量打印 PDF 插件）

一句话：把 DWG 里的一张张图框打成单页 PDF，再合成一本
「图纸合集」，顺手出一份图纸目录。

适用环境
------------------------------------------------------------
- 系统：Windows 7 / 10 / 11（64 位）
- CAD：AutoCAD 2013-2024（R19-R24.3），天正 T20 / T30
- 不用装 Visual Studio、不用 .NET SDK、不用联网、不用 NuGet


一、安装（3 步）
------------------------------------------------------------
1. 从 GitHub 下载本仓库的 ZIP，解压到任意目录
   （不要放在带中文的路径里，路径不要太深）。
2. 双击「一键安装.bat」。
   Windows 弹「是否允许此应用对你的设备进行更改」时点「是」。
   安装器会自动找 CAD、用 Windows 自带的 C# 编译器现场编译、
   部署到自动加载目录，全程写 install.log。
   - 有管理员权限：装到 C:\Program Files\Autodesk\ApplicationPlugins
   - 没有管理员权限：装到用户目录，并自动把该目录追加进
     CAD 的受信任位置（TRUSTEDPATHS），不用手工去「选项」里加。
3. 完全关闭并重新打开 AutoCAD / 天正，
   顶部菜单栏出现「K-批量打印」。

装完找不到菜单？
  命令行敲 MENUBAR 回车输入 1；或敲 APPAUTOLOAD 确认是 1；
  或直接敲命令 MP_FRAME、MP_MENU（重建菜单）。
  安装失败先看 install.log，再看 README 第 11 节「故障速查」。


二、菜单与命令（共 4 项）
------------------------------------------------------------
  菜单项                      命令            干什么
  -------------------------  --------------  ------------------------
  批打到文件 (通用型)        MP_GENERAL      遍历所有布局，沿用每个
                                              布局自己的页面设置
  批打到文件 (图框型)        MP_FRAME        核心入口：先管图框库，
                                              再扫描、再批量出 PDF
  打印设置                    MP_PRINTSET     PC3、CTB、颜色、偏移、
                                              线宽、居中、比例、默认
                                              打印机、份数
  一键卸载…                   MP_UNINSTALL    移除菜单、停用自动加载、
                                              清理受信任位置

  附加命令 MP_MENU：重建顶部菜单（菜单万一没挂上时用）。


三、第一次用：图框型批量出 PDF（核心用法）
------------------------------------------------------------
第 1 步：录入图框（只做一次，以后换项目可导入复用）
  1. 菜单点「批打到文件 (图框型)」。
  2. 打开「图框信息库」窗口，点「录入新图框」。
  3. 点「框选图框（自动识别）」，回到图上框选一个图框。
     块名、图号 / 图名 / 版次的 Tag 会自动识别并填好。
  4. 核对三项：图号 (A)、版次 (B)、图名 (C)。
     认不准就双击属性行里的 Tag 直接填，或手动输块名
     （支持 TK_* 这样的通配）。
  5. （建议）点「点取图号范围」/「点取图名范围」，在图上框出
     图号、图名文字所在的小区域。
     区域是按「相对图框的位置」存的，所以同一图框放大缩小
     （1:100、1:150）都能按同一相对位置读，不会读错格子。
     读不到会提示核对位置，「清除范围」可撤销。
  6. 选纸张（A0-A4、加长、自定义宽高）、命名模板等，点「确定」。
     命名模板默认是「图号_图名_图框大小」（图框大小取纸张代号
     如 A1），也可改成老模板 A_C_B、A_C_T、{A}-{C}({B})。
     整套图框库可导出成 JSON，换项目「导入设置」复用。

第 2 步：扫描出清单
  点「开始批打 PDF」，插件按图框库扫描整张图，
  扫到的图框一张一行进清单窗口。

第 3 步：在清单窗口里核对（重点）
  清单每行就是一张图，各列的意思：
    序号        行号
    预览        点一下，按当前这行的纸张和比例渲染一张
                打印预览图，大图里看（可缩放），核对字会不
                会太小、内容有没有被裁、边框有没有缺。
                渲染失败会直接报原因。
    图号 (A)    双击可改
    图名 (C)    双击可改
    版次 (B)    双击可改
    纸张        点下拉框直接改（A0 / A1 / A2 / A3 / A4 /
                加长 / 自定义）。
                改完文件名里「图框大小」那段和「比例」列
                跟着变。选「自定义」用本行实测尺寸。
    比例        导出时真正用的比例（见第四节）。
    文件名      最终 PDF 的名字，双击可改。
    导出状态    待导出 / 正在导出 / 成功 / 失败 / 已跳过
    方向        横向 / 纵向（按图框实际长宽）
    删除        点一下删掉这一行（不用先选中）

  清单上方的批量操作：
    筛选        全部图纸 / 重复图号 / 重复文件名 /
                文件名为空 / 异常图纸
    排序        默认顺序 / 按图号 / 按图名 / 按纸张
    批量设置纸张 / 比例分母 / 应用纸张 / 应用比例 /
    应用命名规则
                选中多行后点，改选中的行；没选中时改
                全部可见行。
    定位选中图纸  回图上看选中图框（可平移 / 缩放），
                按回车返回清单。看图框本身用这个；
                看打印出来什么样用每行的「预览」。
    点选图框    在图上连续点选图框块追加进清单
                （回车结束，Esc 取消）。
                只加你点的块，不扫描整张图；已在清单
                里的块不重复加；你已改的图号 / 纸张
                原样保留。边界读不出的行会标「边界异常」，
                留在清单里等你处理，不会悄悄丢掉。
    图号重排    按顺序重排图号
    删除选中 / 清空清单
    上移 / 下移  选中多行可整批移动（相对顺序不变，
                移动后保持选中）。
    纸张统计    各纸张各有几张
    导出目录CSV  把清单导出成 CSV（序号、图号、图名、
                版次、图框大小、比例、文件名、来源）

第 4 步：确认导出
  点底部「确认导出 PDF」。
  导出前会先检查：文件名是否为空 / 有非法字符 / 重名、
  图框窗口是否有效、纸张与比例是否有效、输出目录是否
  可写。有问题会先报出来让你处理，不会直接出坏 PDF。
  接着弹出整批打印预览（导出前最后确认）：
  一张张看，没问题点「确认导出 PDF」；
  不想看了点「不预览，直接导出」；
  不想打了点「取消」，一张 PDF 都不会生成。
  导出完出结果窗口：成功的、失败的、跳过的各有几张，
  失败的点「重试失败项」只重打失败那几张，不用全部重来。
  输出目录里有：每张的单页 PDF、图纸合集.pdf、
  图纸目录.csv、批打结果.txt。


四、纸张与比例（最容易迷糊的地方）
------------------------------------------------------------
- 「比例」列显示的是导出时真正用的标称比例。
  自动时 = 图框实测尺寸 ÷ 纸张。
  比如 A0 图框（1189×841mm）印在 A0 纸上是 1:100；
  改成 A3 纸（420×297mm）就变成约 1:283，
  比例列马上跟着变。
- 改纸张前先看比例：比例越大，印出来的字越小。
  比例到 1:200 以上那格会变成橙色，提醒你「打印后
  文字可能偏小，请核对」——点「预览」看一眼最稳妥。
- 双击比例格可以手动填分母（填 100 就是 1:100），
  手动填的后面带一个 *，不随纸张变；清空就恢复自动。
- 同一个图框在图里放大缩小（1:100、1:150）都能认：
  插件按插入比例还原真实纸张，A1 就是 A1，
  不会因为图框在模型里是 84100mm 就认成「自定义」。
- 显示的是标称比例（不含 2mm 留白），导出时实际比例
  会再大一点点（1:100 约 1:100.5），差不到 1%，
  不影响判断字大小；预览图是带留白的真实导出效果。


五、其他用法
------------------------------------------------------------
- 通用型（MP_GENERAL）：不按图框库，按布局出图。
  遍历所有布局，沿用每个布局自己的页面设置。
  也可以先选「手动框选」：在图上连续框多个矩形
  （每框一个回车确认，全部框完再回车结束），
  图号 / 图名自动从每个框选区域读出，可在表格里
  双击补填 / 修改，点「开始打印」一次出多张 PDF。
- 图框型也可以手动框选：点图框型菜单后选「手动框选」，
  框选窗口的纸张默认 A3（可改成 A0-A4 / 加长 / 自定义）。
- 打印设置（MP_PRINTSET）：PC3、CTB、颜色、偏移、线宽、
  居中、比例、默认打印机、份数。
  默认居中打印、四边留白 2mm（防边框线被裁掉）。


六、卸载
------------------------------------------------------------
- 菜单点「一键卸载…」（或敲 MP_UNINSTALL），
  或双击仓库里的「卸载.bat」输入 Y 确认。
- 卸载会：移除菜单、停用自动加载、清理受信任位置
  与按需加载注册表项；被 CAD 占用的 DLL 安排在
  下次开机时删除。
- 图框库、设置与日志（%APPDATA%\MPlot）会保留，
  重装后可继续用，不会丢。
- 卸载后重启 CAD，菜单不会再出现。
  如果卸载时 UAC 点了「否」（没给管理员权限），
  菜单同样不会再出现（有磁盘标记拦着），但文件
  还在 Program Files 里；要彻底删干净，
  右键「卸载.bat」→ 以管理员身份运行一次。


七、常见问题
------------------------------------------------------------
Q：菜单找不到？
A：命令行敲 MENUBAR 回车输入 1；或敲 APPAUTOLOAD 确认是 1；
   或直接敲 MP_FRAME、MP_MENU。
   还不行就看 install.log，确认安装时有没有报错。

Q：安装时编译失败？
A：把 install.log 里全部以 error 开头的行发出来，
   或看 README 第 11 节「故障速查」。

Q：点「预览」失败，说缺少设备？
A：本机缺少 PublishToWeb PNG.pc3 预览设备，无法生成预览图。
   这台机器一般自带；换机器没有的话，预览不可用，
   但直接导出 PDF 不受影响（导出用 DWG To PDF.pc3）。

Q：图号 / 图名读错了？
A：先在图框库里对这个图框点「点取图号范围」/
   「点取图名范围」，把图号、图名文字所在的小区域
   框准；再不行看 %APPDATA%\MPlot\logs 里最新的日志，
   「图号细化」那行会写这张图的图号是从哪一步读出来的。

Q：导出后某张 PDF 是空白的？
A：先看清单里那行的纸张是不是「自定义」加一个很大的尺寸、
   比例是不是异常大；再点那行的「预览」看一眼。
   还是空白就看批打结果.txt 里那张的报错。

Q：图框库 / 设置存在哪？
A：%APPDATA%\MPlot（图框库、设置、日志）。
   卸载不会删这里，重装后继续用。

Q：能装在 AutoCAD 2025 / 2026 上吗？
A：2025 起 .NET 不兼容，需要另外的 .NET 8 版本，
   本仓库默认版本只支持到 2024（R24.3）。
